# 变更日志

本文件记录项目的重要变化。

当前项目仍处于 1.0 之前的开发阶段。正式版本发布前，主要变化会先记录在 `Unreleased` 中。

## Unreleased

### 新增

- URL Encode/Decode 增加 `mode=component`，用于数据库密码等 URI 值，解码保留字面量加号；默认仍为 `mode=query`。
- Token 增加 `format=hex|base64|base64url`，明确长度按原始随机字节数计算；默认仍为 32 字节、无填充 Base64URL。
- 增加 Ctrl+R 最近工具列表，保留最近使用的 5 个动作；历史仅持久化工具 ID，选择后定位到对应工作台而不执行，存储不可用时退回会话内历史。

- 受 lazygit 启发的 TUI 布局，支持数字快捷区域。
- 类目和子类目导航。
- 支持搜索类目、子类目和具体工具。
- JSON 工作台，支持美化、压缩、校验、排序、转义、反转义、路径查询和输出链式应用。
- 输入和输出工作区增加明显边框。
- 用于常用命令的上下文快捷键提示。
- 分组命令帮助弹窗，支持过滤。
- 输入和输出半页滚动快捷键。
- 输入编辑器撤销和重做。
- 核心内置工具 registry 级测试。
- 开源项目基础文档：README、贡献指南、行为规范、安全策略和变更日志。

### 变更

- 合并 Convert 的四种格式转换、Base64 三种变体的编解码、Generator 的 Password/Token/UUID v4；57 个动作收敛到 18 个可选入口。共用工作台保留输入、参数草稿和输出来源，搜索与最近记录仍定位具体动作。
- TUI 参数改为统一逐项表单：固定参数名、逐字段编辑和密钥遮罩，Tab/Shift+Tab 切换字段，左右键选择枚举值；空格和引号可原样输入，各动作保留参数草稿和选中字段。
- 分类边框增加上下滚动提示；分组和当前结果标题减少重复动作名称，保留旧结果时仍显示来源，执行反馈改用可读工具名称。
- 提高文档分区标题对比度、收敛粗体；分类使用可读名称并将数量右对齐，主要引导集中于 Input，Output 简化为等待提示。
- 调整 TUI 视觉层级：自适应配色、绿色焦点边框、分类整行高亮、弱化非焦点选择，快捷键提示移除背景色块。
- Workspace 改为开放分区和单行说明，增加空状态引导，Normal 模式下移除编辑器竖线装饰。
- 底栏统一显示 Normal、Insert、Search 和 Help 模式标记；Workspace 标题注明当前编辑字段，Insert 提示明确区分 Enter 和 Esc 的行为。
- Esc 统一按层级退出：关闭帮助、清空搜索、结束编辑，再从 Workspace 返回 Actions、Categories；未筛选的 Categories 保留操作反馈。

- Normal 模式下 Tab/Shift+Tab 切换区域、方括号切换动作，移除 Input/Output 面板选择；粘贴立即预览、编辑停顿 200ms 后预览，过期结果禁止复制、保存和应用。搜索打开后恢复整组动作。
- 所有工具组对齐 JSON 工作台：切换动作保留输入、撤销和输出，在内存中按动作分别保存参数草稿。
- 已知本地转换支持切换预览；网络查询、当前时间和随机生成需要显式执行。
- 所有工作区编辑参数后均可 Enter 执行；Apply 统一清空已应用的成功结果并阻止回填错误信息。
- 共用工作区尺寸计算、底栏提示、工具组/动作命名和输出来源标记。

- Categories 内输入文字即可搜索，上下方向键选择类目，移除常驻 Search 区域。
- TUI 数字快捷键对应三个区域：Categories（1）、Tools/Actions（2）、Workspace（3）。
- JSON 顶部显示可选择的动作，共享同一份输入；切换动作预览结果，仅 Query 显示 Path。
- 所有工作区统一选中与编辑规则：`i` 编辑、Enter 执行、`s` 保存、`p` 应用输出。
- 常用动作提示移至底栏，把空间留给输入和输出。

- README 改为更符合开源项目规范的文档结构。
- 通用工具 UI 可以根据工具是否需要输入自适应。
- JSON 类目使用单一工作台页面，不再拆成多个原子 JSON tab。
- CLI 运行时错误现在只输出一条可执行的错误信息，不再重复打印 Cobra usage。
- 产品和开发文档中的 JSON path、Base64 URL、时间、UUID、token 示例已对齐当前真实命令。

### 修复

- 帮助根据视口宽度排版，长快捷键不再截断；弹层裁切保留完整 ANSI 颜色序列。
- 编辑 Options 或 JSON Path 时撤销/重做不再误改 Input；敏感参数格式错误时不再回显密钥片段。
- 搜索结果执行实际选中的 JSON 动作，不再始终美化 JSON。
- 输出方向键传递到当前 viewport，操作通知可见，底栏提示限制在终端宽度内。
- JSON 输出标题不再遮住最后一行，错误信息不能通过 Apply 覆盖输入。
- JSON Check 独立显示校验状态，不覆盖数据结果，并统一拒绝重复 key。

- 复制、保存和 pipe 操作使用 trim 后的原始输出，不再使用 viewport 渲染文本。
- 长输入和长输出按面板宽度自动换行。
- JSON 校验快捷键不再与粘贴快捷键冲突。
- 生成器参数遇到非法数字时会直接报错，不再静默回退默认值。
- TUI 参数解析会在运行工具前校验必填参数和未知参数。
- TUI 参数值支持带引号的空格内容，例如 `replacement="hello world"`。
- 敏感参数会在 TUI 普通工作区视图中遮蔽显示。
- 文本命名风格转换会保留 Unicode 字母和数字，不再丢弃非 ASCII 词。
- JWT 解码会拒绝缺段或多段 token，不再接受非标准形态。
- JWT 解码要求 header 和 payload 段必须是 JSON。
- Network 解析类工具遇到空输入或仅路径输入时会返回清晰错误。
- URL 解析支持 `example.com/path` 这类常见的无 scheme 主机输入。
- URL 解析会保留 `mailto:` 等 opaque URL 的数据。
- HTTP Header 转 JSON 会把重复 header 值保留为数组。
- CSV 转 JSON 会拒绝空表头和重复表头，避免生成有歧义的输出。
- CLI 工具命令现在支持 `-hello` 和负数时间戳这类短横线开头输入，不再要求手动添加 `--`。
- 时间戳转换现在按数字位数判断秒、毫秒和纳秒，不再把正负号计入位数。
- 时间输出现在会避免 Go 原生纳秒范围外的 `UnixNano` 未定义溢出值。
- Base64 和 Hex 解码现在会忽略复制或换行展示带来的格式化空白。
- 没有参数选项的 CLI 工具现在支持 `--hello` 这类双短横线开头输入，不再要求额外添加 `--` 分隔符。
- TUI 中无输入工具如果没有可配置参数，现在不会再显示不可用的 `options` 快捷键。
- HTTP Header 转 JSON 现在会先规范化大小写不敏感的 header 名，再合并重复值。
- JSON 路径查询现在会把已存在的 null 值输出为 `null`，不再显示为空行。
- 有损 JSON 转换现在会在排序 JSON 或 JSON 转 YAML 前拒绝重复对象 key。
- JWT 解码现在会输出合法 JSON 对象，方便继续链到 JSON 工具处理。
- JWT 解码现在会拒绝 header 或 payload 不是 JSON 对象的输入，包括对象 key 重复的情况。
- 文本排序和去重工具现在不会把文件末尾换行当成额外空行处理。
- URL 解析现在支持 `[::1]:8080/path` 这类无 scheme 的 bracketed IPv6 主机输入。
- 时间戳单位判断现在会忽略前导零填充，再判断秒、毫秒或纳秒。
- YAML 转 JSON 现在会先规范化标量 map key，并拒绝规范化后重复的 key 或 alias 循环。
- YAML 转 JSON 现在会拒绝多文档 YAML stream，不再静默只转换第一段文档。
- JSON 路径查询现在会拒绝重复对象 key，不再返回有歧义的值。
- URL 解析现在会拒绝 `http` 或 `https` 等网络 URL scheme 缺少 host 的输入。
- HMAC 工具现在会在共享工具实现层拒绝空 key，不再只依赖 CLI/TUI 参数解析。
- CSV 转 JSON 现在会在使用表头作为 JSON 对象 key 前去掉首尾空白。
- 文本命名风格转换现在会保留 camelCase 和缩写词的词边界。
- 补充项目 Agent 规范引用的 `RTK.md`。
