# sharp v0.1.0

First release notes prepared for review. This file does not mean v0.1.0 has been published.

Sharp is a local terminal toolkit with 57 actions, available through both a keyboard-driven TUI and scriptable CLI.

## Highlights

- A shared Input/Options/Output workspace with live previews for local transformations, fixed-label parameter forms, undo, apply, copy and save.
- Vim-style category navigation with j/k, explicit s or / search, h/l action selection, and a persistent five-item recent-tools picker.
- JSON formatting, validation and querying; text and regex helpers; hash/HMAC; URL and query inspection; date/time; format conversion; JWT inspection.
- URL component encoding for individual URI values, and secure tokens with raw-byte sizing and hex/Base64/Base64URL output.
- Related conversions, Base64 variants and generators share groups, reducing the category list to 18 entries.

## Downloads and installation

Release archives cover macOS and Linux on amd64 and arm64. Each includes the binary, Apache 2.0 license, and English/Chinese README; SHA256 checksums are in checksums.txt. See the README for installation and PATH troubleshooting.

After this version is published, Go users can install with:

```sh
go install github.com/gkmz/sharp/cmd/sharp@v0.1.0
```

## Known limits

- This is pre-1.0 software; commands, defaults and keybindings may evolve. Behavior changes will be documented.
- Windows is not included in the supported release matrix. macOS binaries are not Developer ID signed/notarized; archives and checksums are not cryptographically signed.
- Clipboard operations use the platform clipboard provider; Linux users may need xclip or xsel and a graphical clipboard session. Core CLI transformations do not need a clipboard.
- JWT decoding inspects contents without verifying signatures. Network DNS lookup explicitly accesses the network.
